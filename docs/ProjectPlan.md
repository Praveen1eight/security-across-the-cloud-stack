# Security Across the Cloud Stack

## Objective

Build a practical Microsoft Azure cloud security project demonstrating security across:

- Infrastructure as a Service (IaaS)
- Platform as a Service (PaaS)
- Software as a Service (SaaS)
- Microsoft Entra ID

The project applies Microsoft's Shared Responsibility Model through practical security controls, security analysis, governance, monitoring, and infrastructure automation.

---

## Goals

- Learn Azure by building
- Implement cloud security best practices
- Demonstrate Azure Identity and Access Management
- Secure workloads across IaaS, PaaS, and SaaS
- Implement Governance
- Implement Defender for Cloud security assessment
- Implement Monitoring and Logging
- Implement Infrastructure as Code using Azure Bicep
- Build security analysis and risk-scoring capabilities
- Document the complete implementation
- Publish the project on GitHub
