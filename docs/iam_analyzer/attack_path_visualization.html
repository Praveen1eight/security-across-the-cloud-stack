Why It Matters

The identity 'Current Azure User' has the 'Key Vault Secrets Officer' role, which provides access to the Key Vault containing 'app-secret'.

Potential Impact

Compromise of this identity could allow an attacker to access sensitive Key Vault data.

Remediation

Action
Review the 'Key Vault Secrets Officer' role assigned to 'Current Azure User' and remove the assignment if access to 'app-secret' is not required.

Least Privilege
If access is required, replace the role with the least-privileged role that provides only the required operation.

Verification
Verify that 'Current Azure User' no longer has unnecessary access to 'app-secret'.

Why It Matters

The workload 'security-cloud-stack-app-01' uses a managed identity that is assigned the 'Key Vault Secrets User' role. That role provides access to the Key Vault containing 'app-secret'.

Potential Impact

If the workload or its managed identity is compromised, an attacker may be able to access the sensitive secret.

Remediation

Action
Review the 'Key Vault Secrets User' assignment for 'security-cloud-stack-app-01' and remove the role if the workload does not require access to 'app-secret'.

Least Privilege
If access is required, replace the broad role with the minimum permission needed for the workload.

Verification
Verify that 'security-cloud-stack-app-01' can no longer reach 'app-secret' through an unnecessary role assignment.
